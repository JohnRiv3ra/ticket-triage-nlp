# Ticket Triage NLP

Sistema que clasifica y prioriza automáticamente tickets de soporte técnico
usando Procesamiento de Lenguaje Natural.

## Estado
🚧 En desarrollo — proyecto de aprendizaje

## Tecnologías (planificadas)
- Python, scikit-learn (modelo de clasificación)
- FastAPI (API)
- SQLite / PostgreSQL (base de datos)
- React (interfaz)
